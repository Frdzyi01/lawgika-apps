1
Fix Bug Search Podcast Room Bookings
Bug Fix

Deskripsi Masalah

Ketika melakukan pencarian (search) di halaman reservasi Podcast Room, sistem menampilkan error SQL:

SQLSTATE[42S22]: Column not found: 1054 Unknown column 'email' in 'where clause'

Kolom 'email' tidak ada pada tabel podcast_room_bookings, namun query pencarian tetap mencoba mencari di kolom tersebut.
Solusi
Menghapus kolom 'email' dari query pencarian pada controller Podcast Room karena kolom tersebut tidak ada pada tabel database podcast_room_bookings.
File yang Diubah
  • app/Http/Controllers/Admin/PodcastRoomController.php

Fix 403 Unauthorized — Checkout Meeting Room
Security Fix

Deskripsi Masalah

Ketika Admin Order (admin1@example.com) mencoba melakukan checkout pada sesi meeting room yang sebelumnya di-checkin oleh Admin SPV (admin@example.com), sistem menolak aksi tersebut dan menampilkan error 403 Unauthorized action.
Penyebab
Middleware / policy controller membatasi aksi checkout hanya bisa dilakukan oleh admin yang sama yang melakukan checkin.
Solusi
Memperbarui logika autorisasi agar semua admin yang memiliki akses ke manajemen meeting room bisa melakukan checkin dan checkout, tidak terbatas pada admin yang melakukan checkin awal.
File yang Diubah
  • app/Http/Controllers/Admin/MeetingRoomController.php [MODIFIED]

Upgrade

Fix 403 Unauthorized — Akses Data Client
Security Fix

Deskripsi Masalah

Ketika Admin Order membuka halaman detail pesanan (/admin/orders/2) dan mengklik link "Data Client", sistem menampilkan error 403 Unauthorized Access karena route Data Client hanya diizinkan untuk role admin (SPV).
Solusi
Memperbarui middleware route untuk fitur Master Client agar juga mengizinkan akses oleh role admin1 (Admin Order) dan spv, sehingga semua admin bisa melihat data client dari halaman detail order.

Fitur Baru

Fix SQL Error — Field 'participants' & Migrasi Database
Bug Fix

Deskripsi Masalah

Setelah implementasi auto-create reservasi dari benefit, ditemukan 2 error SQL berturut-turut:

Error 1: Field 'participants' doesn't have a default value
Kolom participants pada tabel meeting_room_bookings bersifat wajib (NOT NULL) tanpa default value.

Error 2: Field 'date' doesn't have a default value
Kolom date dan start_time pada tabel podcast_room_bookings bersifat wajib.
Solusi
  1. Menambahkan nilai default participants = 1 pada service yang membuat reservasi otomatis.
  2. Membuat migrasi database baru untuk mengubah kolom date dan start_time menjadi nullable pada tabel podcast_room_bookings.
File yang Dibuat / Diubah
  • app/Services/RoomBenefitService.php [MODIFIED]
  • database/migrations/2026_07_14_144036_make_date_and_start_time_nullable_in_podcast_room_bookings_table.php [NEW]
